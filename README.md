# Algorithm Engineer OS · 算法工程师学习计划

> 定位：以「算法工程师」为目标岗位的成长系统，参考 `AI-System-Architect-OS` 的「学习 → 沉淀 → 案例 → 项目 → 复盘 → 面试」闭环来组织。
>
> 一句话目标：12 个月内，兼顾工作，围绕「全国一线城市 + 合肥 · Agent 应用开发工程师（社招，工资优先）」目标，以 LLM/RAG/Agent 为核心，把 NLP、计算机视觉、语音、多模态作为 Agent 的多模态输入/输出能力。

## 这套计划回答三个问题

1. 市场要什么：算法岗的共性要求、岗位细分、2026 年趋势（见 `00-岗位与定位/市场岗位调研.md`）
2. 我现在在哪：对照岗位要求做能力画像和差距分析（见 `00-岗位与定位/个人能力画像.md`）
3. 怎么到那里：按阶段推进公共地基、NLP、CV、语音、多模态、项目、面试（见 `02-技术地图/学习路线总览.md`）

## 市场调研结论（摘要）

2026 年算法岗的共性要求可以概括为：

```
数学与统计
    ↓
Python + 数据结构与算法
    ↓
机器学习 + 深度学习
    ↓
大模型 / RAG / Agent
    ↓
数据工程 + 工程化部署
    ↓
业务指标与交付能力
```

单一技能不够，算法岗越来越像「懂模型的工程师」：既要能推导原理，也要能写工程代码、治理数据、做评测、上线和迭代。

在能力结构上不押单一方向：NLP、计算机视觉、语音、多模态都要有项目或可演示能力。但求职核心是 Agent 应用工程：LLM 原理、RAG、工具调用、向量库、后端部署、评测。

## 能力模型

| 能力维度 | 核心内容 | 状态 |
| --- | --- | --- |
| 数学与统计 | 线性代数、概率统计、微积分、优化理论 | 待补强 |
| 编程与算法 | Python、C++/Java 之一、数据结构、LeetCode | 有基础，需刷题 |
| 机器学习 | 经典模型、特征工程、评估、A/B 实验 | 待系统化 |
| 深度学习 | PyTorch、CNN/RNN/Transformer、训练调优 | 有基础，需深化 |
| 大模型与 AI 工程 | LLM 原理、RAG、Agent、微调、评测 | 有经验，需工程化 |
| Agent 应用工程 | Function Calling、MCP、多 Agent、记忆、向量库、后端 | 核心目标，需系统补 |
| 多领域覆盖 | NLP 深化、CV/语音/多模态作为 Agent 输入输出 | NLP 有基础，其余从零 |
| 数据与平台 | SQL、Pandas、Spark、Docker、MLOps | 主要缺口 |
| 业务与面试 | 业务指标、Bad Case、项目叙事、面试题 | 贯穿全程 |

## 阶段总览

| 阶段 | 时间 | 主线 | 关键产出 |
| --- | --- | --- | --- |
| 0 定位与准备 | 第 1 月 | 岗位调研、环境搭建、第一个 RAG/Agent Demo | 个人画像、启动决策、最小 Demo |
| 1 Agent 工程核心 | 第 2–4 月 | LLM 原理、RAG、Function Calling、向量库、后端 | RAG 知识库项目 |
| 2 Agent 深潜 | 第 5–7 月 | MCP、多 Agent、记忆、评测、部署 | Agent 自动化项目 |
| 3 多领域支撑 | 第 8–10 月 | OCR、ASR、TTS、VLM 集成进 Agent | 多模态 Agent 项目 |
| 4 面试冲刺 | 第 11–12 月 | 刷题、理论、项目叙事、模拟面试 | 可投递简历 + 面试题库 |

> 按每天 1–2 小时（约每周 8–12 小时）设计：3 个项目 + 刷题 + 面试并行，每周再留 2–3 小时补数学/ML/DL 理论。

## 使用方法

1. 先读 `00-岗位与定位/市场岗位调研.md`、`一线城市Agent岗位调研.md`、`一线城市算法工程师岗位调研.md`、`启动决策摘要.md` 和 `个人能力画像.md`
2. 按 `02-技术地图/学习路线总览.md` 推进，第 1 个月先执行 `启动计划-第1月.md`，第 1 周按 `启动计划-第1周.md` 执行
3. 每个知识点用 `01-学习方法/技术学习模板.md` 沉淀
4. 每完成一个阶段或项目，写 `06-学习日志/` 和周复盘
5. 最后 2 个月进入 `08-面试准备/`

**计划控制规则**：所有推荐动作从 `任务清单.md` 的第一个未完成任务读取；每次完成任务后更新 `当前状态.md`；计划调整统一记录在 `总计划.md`。
