# 07-问题库

记录学习中未解决的问题，防止「没搞懂就跳过」。

## 模板

```markdown
## [日期] 问题

### 问题描述
...

### 我已经查过
...

### 卡住的原因
...

### 下一步
...
```

## 规则

- 问题必须写清楚「我卡在哪一步」，不能只写一个术语
- 解决后保留「解法 + 一句话本质」，不删除原问题
- 每周复盘时检查未解决问题，判断是否需要回到前置知识
