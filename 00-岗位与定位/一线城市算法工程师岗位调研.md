## 三、算法岗共性要求

算法工程师岗位普遍比 Agent 应用岗更看重：

1. 数学：线性代数、概率统计、微积分、优化
2. 数据结构与算法：LeetCode 中等以上，数学题约占 20%
3. 机器学习：LR、GBDT、SVM、聚类、降维、特征工程、评估
4. 深度学习：CNN、RNN、Transformer、训练调优、损失与优化器
5. 框架：PyTorch、HuggingFace、实验追踪
6. 大模型：预训练/微调、LoRA、RLHF/DPO、RAG、Agent、评测
7. 工程：Docker、模型部署、推理优化、监控
8. 加分：论文、竞赛、开源贡献、垂直领域经验

## 四、与 Agent 应用岗的差异

| 维度 | Agent 应用开发工程师 | 算法工程师 |
| --- | --- | --- |
| 核心 | LLM/RAG/Agent 产品落地 | 模型训练、调优、评测、迭代 |
| 面试重点 | 项目、系统设计、工具调用 | 数学推导、模型原理、代码、论文 |
| 学历门槛 | 本科可投，硕士加分 | 硕士/博士更常见 |
| 薪资上限 | 高，但依赖产品工程能力 | 更高，依赖算法深度 |
| 12 个月可行性 | 较高 | 较难，但可并行准备 |

## 五、对你的启示

1. 算法工程师岗位薪资上限更高，但门槛也更高，需要补数学推导、经典 ML/DL 和面试刷题。
2. 你的 RAG/Agent 经验可以同时支撑两条线：Agent 应用岗直接作为主攻，算法岗作为并行目标。
3. 大模型、NLP、CV、语音四领域算法岗都要求 Transformer 和评测能力，公共地基值得投入。
4. 作品集项目同时满足两条线：RAG/Agent 项目证明应用能力，再补一个带评测和训练的算法项目。
5. 12 个月时间有限，主线仍以 Agent 应用岗为主，算法岗准备放在公共地基和面试阶段强化。
