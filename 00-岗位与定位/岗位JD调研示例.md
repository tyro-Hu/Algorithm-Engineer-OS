# 岗位 JD 调研示例

> 示例填写，用来展示模板怎么用。真实投递前必须到原 JD 核对最新要求。

## 示例 1：AI Agent 应用工程师（北京/上海/南京）

### 岗位信息

| 字段 | 内容 |
| --- | --- |
| 公司 | 某 AI 芯片公司 |
| 城市 | 北京 / 上海 / 南京 |
| 岗位名称 | AI Agent 应用工程师 |
| 薪资范围 | 55–75 万/年 |
| 工作年限 | 0 年（硕士以上） |
| 学历要求 | 硕士以上 |
| JD 链接 | [锐仕方达](https://m.risfond.com/jobs/content-536014) |

### 核心要求

- LLM / Prompt：掌握大语言模型应用
- RAG / 知识库：构建智能支持 Agent，理解客户问题，提供知识推荐
- Agent / 工具调用：有 AI Agent 项目实战经验
- 工程：精通 C/C++、Python，具备前后端集成和全流程落地能力
- 加分：LangChain、AutoGen、Semantic Kernel，芯片工具链背景

### 我的差距

- 有 RAG/LLM 应用基础，但缺完整 Agent 框架实战
- 缺全栈集成和前后端落地经验
- 缺复杂工具链/客服系统场景

### 项目映射

- 项目 2（Agent 自动化）可以证明工具调用和多 Agent 能力
- 项目 1（RAG 知识库）可以证明知识库与支持系统能力

### 结论

这个岗位薪资高、方向匹配，重点补 Agent 框架和全栈工程。

## 示例 2：AI Agent 应用开发工程师（杭州 · 阿里）

### 岗位信息

| 字段 | 内容 |
| --- | --- |
| 公司 | 阿里巴巴集团 |
| 城市 | 杭州 |
| 岗位名称 | 业务技术-AI Agent 应用开发工程师 |
| 薪资范围 | 30–50k/月 |
| 工作年限 | 经验不限 |
| 学历要求 | 本科以上 |
| JD 链接 | [猎聘](https://www.liepin.com/job/1984773923.shtml) |

### 核心要求

- Agent 架构、上下文工程、知识工程
- 数据意识：数仓建模、数据挖掘、大数据存储与分析
- 工程基础：用大模型做需求理解和方案设计
- 加分：AI IDE 工具研发、toB/toP 侧 AI 应用经验

### 我的差距

- 上下文工程和知识工程需要系统补
- 数仓建模和大数据引擎不熟
- 缺 toB/toP 侧真实业务场景

### 项目映射

- 项目 1（RAG 知识库）覆盖知识工程
- 项目 2（Agent 自动化）覆盖 Agent 架构
- 需要补一个数据分析或业务数据项目

### 结论

工程和数据能力并重，不只是“会调模型”。

## 示例 3：算法工程师（深圳 · LLM/VLM）

### 岗位信息

| 字段 | 内容 |
| --- | --- |
| 公司 | 深圳市亿道数码技术有限公司 |
| 城市 | 深圳 |
| 岗位名称 | 算法工程师 |
| 薪资范围 | 20–35k/月 |
| 工作年限 | 未明确 |
| 学历要求 | 硕士以上，博士优先 |
| JD 链接 | [福建人才联合网](http://fjrclh.fzu.edu.cn/cms/jobDetails.html?jobId=50150&zhaopinhuiId=) |

### 核心要求

- LLM/VLM 预训练、微调（SFT/RLHF/DPO）、对齐、性能优化
- Transformer、MoE、长上下文、Scaling Law
- 分布式训练：DeepSpeed、Megatron
- 数据配比、数据清洗、合成数据、评测平台
- 加分：顶会论文、Kaggle/KDD Cup 前 5%、开源贡献

### 我的差距

- 分布式训练没有实战
- SFT/RLHF/DPO 只有概念
- MoE、Scaling Law、数据配比不熟
- 评测平台没有系统做过

### 项目映射

- 需要一个「训练 + 评测」型项目，例如 LoRA 微调 + 评测集 + Bad Case 分析
- 项目 1（RAG 评测）覆盖评测思维，但算法岗还要求训练能力

### 结论

算法岗门槛更高，12 个月内作为并行目标，优先保证 Agent 应用岗竞争力，再补训练与评测项目。
