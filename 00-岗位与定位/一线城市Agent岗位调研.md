## 二、高薪岗位的共性要求

高薪 Agent 应用岗普遍要求：

1. 深入理解 LLM 原理、Prompt、Context Engineering
2. 有 Agent 实战项目：工具调用、Function Calling、MCP
3. 有 RAG 端到端经验：分块、Embedding、混合检索、重排、向量库
4. 熟悉多 Agent 架构：规划、记忆、通信、失败重试
5. 有后端工程能力：Python/Java、FastAPI、Docker、数据库
6. 能独立完成系统设计：稳定性、可扩展性、成本、延迟、评测
7. 加分项：模型微调、推理优化、多模态输入

## 四、对你的启示

1. 高薪岗位的核心竞争力是「能把 Agent/RAG 做成稳定可用的产品」，不是只写 Demo。
2. 12 个月内必须打磨出 3 个能讲清设计、指标、失败模式的完整项目。
3. 后端和系统设计能力决定薪资上限：FastAPI、Docker、数据库、延迟/成本优化都要补。
4. 面试会问「为什么这样设计」「如果挂了怎么办」，项目复盘比项目数量更重要。
5. CV、语音、多模态仍然是加分能力，但主线是 LLM/RAG/Agent 工程。
