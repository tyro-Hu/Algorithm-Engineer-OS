# Agent 开发岗位调研报告（2026-08-24）

> 调研目的：用真实招聘要求校准学习计划，避免拍脑袋。
> 覆盖平台：Boss直聘、牛客网、智联招聘、猎聘、拉勾、高校就业网、国家大学生就业平台、V2EX、海外职位库（Dice / LinkedIn / 官网）。
> 覆盖公司：腾讯、字节（Seed / 火山方舟）、阿里（淘天 / 阿里云）、美团、百度、京东、华为、中国移动、科大讯飞、海澜智云、涂鸦、海尔等，以及海外 OpenAI / Anthropic 生态岗位。

## 一、结论前置：这是一个「光谱」，不是单一岗位

「Agent 开发」从低到高是一个连续带，两端的技能、门槛、薪资完全不同。

```
应用型 Agent 开发（招聘池最大）       算法型 Agent（技术壁垒最高）
Python + 工程 + RAG + 框架     ←→     Transformer + SFT/RLHF/Agentic RL
本科可进、1-3年可做                硕士+/博士、3年+++ 深度
15-40k（一线）                    50-80k+（一线大厂）
```

## 二、应用型 Agent 开发：真实技能要求

### P0 必备（几乎每份 JD 都有）

- 编程语言：Python 是 100% 门槛（精通级）；Java / Go / TypeScript 作为第二语言（美团聚的 TypeScript/Node，阿里淘天 Java）
- 扎实工程基础：数据结构与算法、编码规范、计算机网络、调试能力
- 后端能力：数据库 / 缓存 / 消息队列、微服务、REST/FastAPI（20%+ 岗位明确要 FastAPI）
- LLM 应用：熟悉 OpenAI / Claude / Qwen / DeepSeek / LLaMA 等至少一类 API，Prompt Engineering（~45%）、Function Calling / Tool Use
- RAG（~60%）：分块、Embedding、矢量检索、混合检索、重排、引用；矢量数据库（Milvus / Qdrant / Chroma，~40%）
- Agent 框架（~80% 提到 LangChain；LangGraph 是生产标配）：Chain / Agent / Memory / Tool，能搭可运行的 Agent
- MCP（快速上升）：会做 MCP Server、SkillSet、工具封装（海外已单列「MCP Engineer / Agentic AI & MCP Specialist」）

### P1 建议 / 加分

- AI 编码工具（2026 增长最快）：Cursor、Claude Code、Opencode、Copilot，「重度 AI Coding 用户」已进入美团等 JD
- FastAPI / WebSocket，前后端联调；全栈（React/Vue）加分
- 低代码平台：Dify、Coze
- 多 Agent 编排：AutoGen、CrewAI、SuperAGI、Agentscope
- 生产化：Agent 能跑、能优雅失败、能恢复；Observability / 评测（大量团队在做 Agent 可观测）
- 本地部署：Ollama，vLLM / LMDeploy 概念

### 服务端与架构要求（大厂中高级）

- 系统设计复杂业务抽象、高可用、高扩展；主导客户端/多 Agent 协同框架设计
- 微服务 + 分布式，大数据处理与清洗

## 三、算法型 Agent：真实技能要求

代表岗位：字节 Seed / 火山方舟「Agent 算法工程师」、阿里「算法工程师-大模型后训练」、腾讯「大模型 Agent / Post-training」、上海 AI Lab「Agent 后训练」。

### 硬要求

- 学历：硕士及以上（研究向偏好博士、顶会）；计算机 / 数学 / 机器学习相关
- 模型原理：深度学习、Transformer 架构细节、Diffusion（部分）、LLM 训练流程（Pre-training → SFT → RLHF/Post-training）
- Post-training：SFT、LoRA/QLoRA、DPO、RLHF、GRPO、PPO；优先有 Agentic RL（Agent 通过奖励信号自我改进）实操
- 强化学习框架：Verl / AReal / Slime 等至少一款
- 训练工程：分布式训练、推理优化、vLLM/SGLang/LMDeploy、评价体系与数据质量
- 加分：顶会论文 / 竞赛 / 能独立做算法研究与优化、模型诊断、国产硬件适配

## 六、趋势信号（决定你该往哪补）

1. 应用侧需求最旺、入门门槛最低，但会越来越卷：越来越多人都能调 LLM API。
2. 生产化是分水岭：从「能 demo」到「能跑、能失败、能恢复、可观测」，是 3–5 年岗的硬要求。
3. MCP / A2A 正在成为工程标准：不仅是 Function Calling，还要会写 MCP Server、工具封装、技能编排。
4. AI Coding 工具成为招聘关键词：Cursor / Claude Code / Opencode 已是部分 JD 的必写项。
5. 高壁垒在「Post-training + Agentic RL」：字节、阿里、腾讯明确要求 SFT/RLHF/DPO/GRPO/PPO + Agentic RL，这正是算法岗溢价所在。

## 七、对你计划（24 个月）的含义

1. 主攻「Agent 算法工程师（LLM + Agent + RL + Post-training）」方向与真实高壁垒岗一致，成立。
2. 但应用型 Agent 开发是最大、最快能上岗的池子，且是承载算法能力的项目载体，必须做扎实。
3. 落地优先级调整：
   - 早期先把应用侧真实工具补齐：LangChain/LangGraph、MCP Server、AI 编码工具、RAG、FastAPI、生产化/可观测。
   - 中后期把算法侧硬要求补齐：Transformer 从零、SFT/LoRA/DPO/RLHF、Agentic RL、分布式训练、vLLM。
4. 你的现有课程 1–16（RAG、Function Calling、Agent、MCP、记忆、Docker、FastAPI）已覆盖应用侧大半，重点转向「框架成体系 + 生产化」。
