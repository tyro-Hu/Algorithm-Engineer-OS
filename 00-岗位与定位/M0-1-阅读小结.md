## 二、核心结论（浓缩版）

### 1. 岗位目标

- 主攻：Agent 应用开发工程师，全国一线城市 + 合肥，工资优先
- 并行：算法工程师（大模型 / NLP 方向）
- 周期：12 个月，每天 1–2 小时

### 2. 高薪 Agent 岗要什么

- LLM 原理、Prompt、Context Engineering
- RAG 端到端：分块、Embedding、混合检索、重排、向量库
- Agent：Function Calling、MCP、多 Agent、记忆
- 后端：FastAPI、Docker、数据库、系统设计
- 评测：成功率、延迟、成本、Bad Case

### 3. 算法岗和 Agent 岗的差别

| 维度 | Agent 应用岗 | 算法岗 |
| --- | --- | --- |
| 重点 | 产品落地、系统设计 | 数学推导、模型训练、评测 |
| 面试 | 项目深挖、场景题 | 模型原理、训练细节 |
| 项目 | 可演示产品 | 可复现训练/评测 |

### 4. 你现在的位置

优势：

- Python 扎实
- 深度学习、GNN 研究基础
- RAG 和大模型应用有实践

主要缺口：

- Agent 框架、Function Calling、MCP
- 数学推导、经典 ML/DL
- 后端部署、系统设计、评测闭环
- CV、语音、多模态基本零基础
- 刷题和面试未开始

### 5. 12 个月怎么走

1. 第 1 月：定位 + 环境 + 最小 RAG/Agent Demo
2. 第 2–4 月：RAG 知识库项目
3. 第 5–7 月：Agent 自动化项目
4. 第 8–10 月：多模态 Agent + LoRA 微调评测
5. 第 11–12 月：双线面试冲刺
