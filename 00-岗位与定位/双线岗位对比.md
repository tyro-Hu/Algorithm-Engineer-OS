# Agent 应用岗 vs 算法工程师：双线准备

> 2026-08-13

## 一、能力对比

| 能力 | Agent 应用开发工程师 | 算法工程师 |
| --- | --- | --- |
| LLM 原理 | 会选模型、会调 Prompt、懂上下文 | 能推导、能解释训练和推理 |
| RAG | 会做端到端，会优化检索 | 会设计评测，理解检索质量 |
| Agent | 必须熟练工具调用、MCP、多 Agent | 加分项，偏向 Agent 规划与训练 |
| 数学 | 够用即可 | 面试硬门槛 |
| 数据结构 | 中等题 | 中等偏难，数学题多 |
| 模型训练 | 了解 | 核心能力 |
| 系统设计 | 核心 | 一般 |
| 项目要求 | 产品可演示 | 训练/评测可复现 |

## 二、面试差异

### Agent 应用岗

- 项目深挖：为什么这样设计、挂了怎么办
- 系统设计：延迟、成本、可扩展、安全
- 工程题：API、数据库、缓存、部署
- 场景题：把业务问题拆成 Agent 流程

### 算法岗

- 数学推导：梯度、贝叶斯、SVD
- 模型原理：Transformer、损失、优化器
- 训练细节：过拟合、数据泄漏、A/B
- 论文/项目：有没有训练过、评测过、迭代过

## 三、12 个月分配建议

| 月份 | 主线 | 双线兼顾 |
| --- | --- | --- |
| 1–4 | RAG 项目 + Agent 工程 | 每周留 2–3 小时补数学/ML/DL |
| 5–7 | Agent 项目 + 部署 | 补 Transformer 原理与评测 |
| 8–10 | 多模态 Agent + 支撑领域 | 做一个 LoRA 微调 + 评测项目 |
| 11–12 | 面试冲刺 | 两类岗位分别准备题库和叙事 |

## 四、项目映射

| 项目 | 主要覆盖 |
| --- | --- |
| RAG 知识库 | Agent 岗：RAG + 后端；算法岗：检索评测 |
| Agent 自动化 | Agent 岗：核心 |
| 多模态 Agent | Agent 岗：多模态集成；算法岗：VLM/OCR/ASR 理解 |
| LoRA 微调 + 评测 | 算法岗：训练与评测；Agent 岗：微调加分项 |

## 五、结论

- 主攻 Agent 应用岗，12 个月可行性最高
- 算法岗作为并行目标，公共地基和面试阶段同时准备
- 至少做一个「训练 + 评测」型项目，保证算法岗也能投
- 简历按岗位定制：Agent 岗突出项目落地，算法岗突出训练和评测
