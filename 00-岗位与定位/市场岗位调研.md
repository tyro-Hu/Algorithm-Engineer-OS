# 市场岗位调研：算法工程师需要什么

> 调研时间：2026-08-13
> 口径：2025–2026 年公开算法岗 JD（字节、美团、小米、海康等）与开源算法学习路线交叉整理

## 一、共性要求

算法工程师岗位虽然方向不同，但底层要求高度一致：

| 类别 | 普遍要求 |
| --- | --- |
| 学历与专业 | 计算机、人工智能、数学、统计、电子信息等本科及以上；大厂研究型岗位硕士/博士优先 |
| 编程能力 | Python 熟练，且至少掌握 C++/Java/Go 中的一门；数据结构与算法扎实；重视代码质量与调试能力 |
| 数学基础 | 线性代数、概率统计、微积分、优化理论；能理解并推导损失函数、梯度下降、正则化 |
| 机器学习 | LR、GBDT/XGBoost/LightGBM、SVM、聚类、降维；特征工程、过拟合、模型评估 |
| 深度学习 | CNN、RNN/LSTM、Transformer、Attention；PyTorch/TensorFlow；训练、调优、损失与优化器设计 |
| 大模型 | Transformer/LLM 原理；SFT、LoRA、DPO/RLHF；RAG/GraphRAG、Agent、Prompt 调优 |
| 数据能力 | SQL、Pandas/NumPy；数据清洗、样本构建、特征处理；大数据场景熟悉 Spark/Flink 更佳 |
| 工程化 | Git、Docker、实验追踪、模型部署、监控、A/B 实验；MLOps/LLMOps 是加分项 |
| 业务与软技能 | 理解业务指标，能分析 Bad Case，推动模型迭代；沟通、协作、自驱、文档表达 |

## 二、岗位细分

| 方向 | 常见职责 | 关键知识 | 与你当前背景匹配度 |
| --- | --- | --- | --- |
| 大模型应用算法 | RAG、Agent、Prompt、微调、评测、上线 | LLM 原理 + AI 工程 + 评测 | 高：已有 RAG/LLM 应用经验 |
| 搜索 / 推荐 / 广告 | 召回、粗排、精排、CTR/CVR、A/B | 特征工程、排序模型、用户建模 | 中：需补推荐体系 |
| NLP 算法 | 文本分类、NER、语义、对话 | Transformer、BERT/GPT、数据标注 | 中高 |
| 计算机视觉 | 检测、分割、OCR、视频理解 | CNN、ViT、OpenCV、数据增强 | 中 |
| 语音算法 | ASR、TTS、声学建模 | 信号处理、声学模型、序列建模 | 低，除非专项兴趣 |
| 多模态算法 | 图文理解、VLM、音视频 | CLIP、Vision-Language、多模态数据 | 中 |
| 风控 / 数据挖掘 | 反欺诈、用户画像、异常检测 | 传统 ML、特征、因果推断、图算法 | 中高：GNN 可迁移 |
| 算法平台 / MLOps | 训练平台、推理平台、模型治理 | 分布式、K8s、推理优化、监控 | 中：可作差异化 |

### Agent 应用开发工程师（一线城市 + 合肥重点目标）

一线城市和合肥当前招聘中，Agent 应用开发 / 大模型应用方向岗位较多，普遍要求：

- 深刻理解 Transformer 与 LLM 原理，熟悉 API 调用与 Prompt/Context Engineering
- 有 RAG 端到端经验：分块、Embedding 选型、混合检索、重排、引用溯源
- 熟悉至少一种向量数据库（FAISS、Milvus、pgvector、Chroma、Qdrant）
- 熟悉 Agent 核心：Function Calling、MCP、多 Agent、记忆、LangGraph/LangChain/LlamaIndex/AutoGen/Dify
- 扎实的 Python/Java 工程能力，FastAPI、Docker、PostgreSQL/Redis 常见
- 加分项：模型微调、推理优化、多模态输入、从 0 到 1 的落地项目

## 三、2026 年趋势

1. 大模型能力成为通用要求：即使不是「大模型算法工程师」，RAG、Agent、Prompt、评测也频繁出现在 JD 中。
2. 算法岗更强调工程闭环：不再只看「模型指标」，而是看「数据 → 训练 → 评测 → 上线 → 迭代」全链路。
3. 评测与数据治理变硬技能：会做评测集、Bad Case 分析、数据清洗、合成数据，比只会调参更有竞争力。
4. 垂直领域经验更值钱：通用算法能力是门票，金融、医疗、制造、教育等领域的业务理解决定上限。
5. 编码面试仍然是硬门槛：大厂普遍考 LeetCode 中等难度以上，数学题约占 20%，模型原理问得很深。

## 四、四领域知识速查

| 领域 | 必备知识 | 常见任务 | 常用工具/数据 |
| --- | --- | --- | --- |
| NLP | 语言学基础、词向量、预训练模型、序列标注、文本生成、LLM | 文本分类、NER、QA、摘要、对话、RAG/Agent | HuggingFace、spaCy、GLUE、DuIE、CMRC |
| 计算机视觉 | 图像处理、OpenCV、CNN、ViT、目标检测/分割/跟踪 | 图像分类、检测、分割、OCR、人脸、视频理解 | PyTorch、MMDetection、COCO、ImageNet |
| 语音 | 信号处理、FFT、频谱、MFCC/FBank、声学模型、语言模型 | ASR、TTS、声纹、语音增强、语音大模型 | WeNet、ESPnet、Whisper、AISHELL、LibriSpeech |
| 多模态 | 跨模态表示学习、对比学习、VLM、图文/音视频对齐 | 图文检索、VQA、图像描述、多模态生成 | CLIP、BLIP、LLaVA、LAION、MSCOCO |

## 五、结论：四条主线

- 主线一（求职核心）：LLM 原理 + RAG + Agent + 向量库 + 后端工程
- 主线二（共同地基）：数学、数据结构算法、机器学习、深度学习按需补
- 主线三（多领域覆盖）：NLP → CV → 语音 → 多模态，作为 Agent 的多模态输入/输出能力
- 主线四（差异化）：用多模态 Agent 项目把四个领域串起来
