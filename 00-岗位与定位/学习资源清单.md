# 算法工程师学习资源清单

> 按「公共地基 → NLP → 计算机视觉 → 语音 → 多模态 → 面试」组织。
> 原则：资源是地图，不是收藏夹。每个资源都要对应一个学习任务或项目。

## 一、公共地基

### 数学与统计

- 《统计学习方法》李航：机器学习经典模型公式与推导
- 《机器学习》周志华：西瓜书，理论体系完整
- 3Blue1Brown《线性代数的本质》：建立矩阵直观
- 吴恩达《机器学习》：入门首选课程
- 《Machine Learning Yearning》吴恩达：模型诊断与偏差方差

### 编程与数据结构

- LeetCode：每日 2–3 题，按专题刷
- 《剑指 Offer》：国内面试高频题
- 《算法图解》：复杂度、递归、图等直观入门
- Python 官方文档 + 《流畅的 Python》：工程化进阶

### 深度学习

- 《动手学深度学习》李沐（PyTorch 版）：边写代码边学
- 《Deep Learning》Goodfellow：花书，理论参考
- CS231n（Stanford）：计算机视觉方向经典课程
- CS224N（Stanford）：NLP 方向经典课程
- PyTorch 官方教程：Dataset、Dataloader、AMP、分布式训练

### 数据与工程

- Kaggle：真实数据集 + 社区 kernel
- SQL：LeetCode SQL 专题 + 《SQL 必知必会》
- Docker 官方文档 + FastAPI 官方文档
- MLflow / Weights & Biases：实验追踪

## 二、NLP

### 书籍与课程

- 《Speech and Language Processing》Jurafsky & Martin：NLP 综合教材
- CS224N：NLP with Deep Learning
- Hugging Face NLP Course：预训练模型实战

### 工具

- HuggingFace Transformers
- spaCy / NLTK / Gensim
- LangChain / LlamaIndex：RAG 与 Agent
- vLLM：推理服务

### 数据集

- GLUE / SuperGLUE：文本理解评测
- SQuAD / CMRC：阅读理解
- DuIE / ACE2005：信息抽取
- 中英文通用语料：Wiki、CLUE

## 三、Agent 应用开发（求职核心）

### 框架与协议

- LangChain / LangGraph：Agent 工作流与多 Agent
- LlamaIndex：RAG 索引与数据框架
- Dify：低代码 Agent 应用平台
- AutoGen：多 Agent 研究型框架
- MCP（Model Context Protocol）：官方文档 + 工具服务封装

### 工具与后端

- FastAPI：Agent API
- Docker：部署
- PostgreSQL / Redis：业务数据与缓存
- 向量库：FAISS、Chroma、Milvus、pgvector
- 流式输出与任务队列：SSE、Celery

### 评测

- RAGAS：RAG 评测
- 自建评测集：任务成功率、Bad Case、延迟、成本

### 开源参考

- Qwen / DeepSeek / OpenAI 兼容 API
- HuggingFace 开源 Agent 项目
- GitHub 上带完整 README 的 RAG/Agent 项目

## 四、计算机视觉

### 书籍与课程

- 《计算机视觉：算法与应用》Richard Szeliski
- CS231n：Convolutional Neural Networks for Visual Recognition
- OpenCV 官方文档 + PyImageSearch 教程

### 工具

- OpenCV
- PyTorch / torchvision
- MMDetection / Detectron2：检测与分割
- Ultralytics YOLO：快速项目原型

### 数据集

- MNIST / CIFAR-10：入门分类
- ImageNet：预训练与分类基准
- COCO / VOC：检测与分割
- 工业缺陷、医学影像等垂直数据集：差异化项目

## 五、语音

### 书籍与课程

- 《语音识别实践》俞栋：ASR 经典教材
- 《语音信号处理》：信号与特征基础
- Hugging Face Audio Course：音频模型实战

### 工具

- librosa / torchaudio：特征提取
- WeNet：中文 ASR，工程化友好
- ESPnet：研究型工具链
- OpenAI Whisper / FunASR：预训练与快速部署
- Kaldi：了解 WFST 解码思想即可

### 数据集

- AISHELL-1/2/3：中文普通话识别
- LibriSpeech：英文 ASR
- Common Voice：多语言开放语音
- NOISEX-92：噪声增强实验

## 六、多模态

### 论文与课程

- CLIP：图文对比学习与 zero-shot
- BLIP / BLIP-2：图文理解与生成
- LLaVA：视觉语言指令微调
- Qwen-VL：开源视觉语言模型

### 工具

- HuggingFace Transformers / OpenCLIP
- LLaVA 官方仓库
- PyTorch + torchvision + torchaudio 联合使用

### 数据集

- MSCOCO：图文描述与检索
- LAION：大规模图文预训练
- ScienceQA / MMMU：多模态评测

## 七、面试

- LeetCode Hot 100 + 剑指 Offer
- 《百面机器学习》：ML 理论高频题
- 大模型算法面试题库（GitHub 开源仓库）
- 牛客网：国内真题与模拟面试

## 使用方式

1. 每周从对应模块取 1–2 个资源，完成后再换，不囤资料
2. 每完成一个资源，写进 `06-学习日志/`
3. 资源解决不了的问题进 `07-问题库/`
