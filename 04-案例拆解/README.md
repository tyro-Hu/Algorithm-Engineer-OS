# 04-案例拆解

本目录存放两类拆解：

## 1. 论文复现

按 `01-学习方法/论文复现模板.md` 记录。四个领域各安排 1–2 篇核心论文：

| 领域 | 建议复现方向 |
| --- | --- |
| NLP | Transformer、BERT、DPR/RAG、ReAct、LoRA |
| 计算机视觉 | ResNet、YOLO 检测链路、U-Net、ViT |
| 语音 | CTC、Conformer、WeNet/Whisper 识别链路 |
| 多模态 | CLIP、BLIP/LLaVA、跨模态检索链路 |

## 2. 真实系统算法案例

拆解知名产品的算法链路，例如：

- 电商推荐：召回 → 粗排 → 精排 → 重排 → A/B
- 搜索引擎：Query 理解 → 召回 → 排序 → 相关性评估
- NLP/大模型知识库：文档治理 → 检索 → 生成 → 引用 → 评测
- 计算机视觉：图像采集 → 预处理 → 检测/分割 → 后处理 → 质量评估
- 语音：音频采集 → 前端增强 → 特征 → ASR → 后处理 → 文本
- 多模态：多源数据 → 跨模态对齐 → 检索/问答 → 评测
- 风控系统：规则 → 图模型 → 机器学习模型 → 人工审核

## 拆解模板要点

- 业务目标是什么？指标是什么？
- 数据从哪来、怎么清洗？
- 特征如何构建？
- 模型如何选、如何评估？
- 上线后如何监控和迭代？
- 失败模式是什么？什么情况下会崩？
