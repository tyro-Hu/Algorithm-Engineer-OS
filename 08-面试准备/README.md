# 08-面试准备

面试准备不是最后两个月才开始，而是从第一天积累：

- `算法刷题路线.md`：LeetCode 模板库和刷题节奏
- `面试知识清单.md`：LLM/RAG/Agent/后端/NLP/CV/语音/多模态高频问题
- `项目叙事模板.md`：项目故事统一结构，3 个项目都按它写
- 3 个项目（RAG、Agent、多模态 Agent）各准备 1 分钟和 5 分钟两个叙事版本
- 每 2 周做一次模拟面试，录下回答复盘

## 面试叙事模板

```
背景：项目解决什么问题，业务/用户是谁
难点：数据、指标、工程、协作上的真正难点
方案：为什么选这个方案，替代方案是什么
结果：离线指标 + 上线效果 + 业务影响
复盘：哪里做错了，如果再来一次会怎么做
```
