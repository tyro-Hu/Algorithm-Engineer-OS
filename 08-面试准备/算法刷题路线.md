# 算法刷题路线

> 目标：LeetCode 250–300 题，形成自己的模板库
> 节奏：每周 8–12 题，约 8–12 周完成一轮

## 刷题原则

1. 先自己想思路，再写代码，最后看题解
2. 每类题形成模板：适用条件 + 代码骨架 + 复杂度 + 边界
3. 错题打标签，两周后重刷
4. 让 AI 解释每一步为什么，而不是直接复制答案
5. 每道题记录一行总结：题型 / 关键技巧 / 易错点

## 专题顺序

### 第一阶段：基础数据结构

- 数组与字符串：20 题
- 哈希表：20 题
- 链表：20 题
- 栈与队列：20 题

### 第二阶段：搜索与分治

- 二叉树与递归：30 题
- DFS / BFS：20 题
- 二分查找：20 题
- 排序：15 题
- 双指针 / 滑动窗口：20 题

### 第三阶段：进阶思想

- 回溯：25 题
- 动态规划：40 题
- 贪心：15 题
- 堆 / 优先队列：15 题
- 图论 / 并查集 / 拓扑排序：20 题

### 第四阶段：冲刺

- 高频综合题：30 题
- 大厂真题复盘：20 题

## 模板库目录建议

```
algorithm-templates/
├── binary_search/
├── sliding_window/
├── backtracking/
├── dp/
├── graph/
├── heap/
└── linked_list/
```

每个模板文件包含：

- 适用场景
- 代码骨架（带中文注释）
- 复杂度
- 3 道代表题 + 错因

## 关键题型清单

- 二分查找（含变体：旋转数组、最值）
- 滑动窗口（最长子串、最小覆盖）
- 双指针（两数之和、三数之和、回文）
- 链表反转、快慢指针、环形链表
- 二叉树遍历、最近公共祖先、路径问题
- DFS/BFS（岛屿、拓扑排序）
- 回溯（全排列、组合、N 皇后）
- DP（爬楼梯、背包、最长子序列、编辑距离、区间 DP）
- 并查集（连通分量、岛屿进阶）
- 堆（Top K、合并 K 个链表）
- 字符串（KMP、回文、字典序）
