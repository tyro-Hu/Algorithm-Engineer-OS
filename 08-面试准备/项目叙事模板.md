# 项目叙事模板

> 每个作品集项目都按这个模板写两版：1 分钟版和 5 分钟版。

## 项目一句话

「我用 X 技术，解决了 Y 问题，结果 Z。」

示例：「我用 RAG + 向量库做了一个知识库问答系统，解决模型不知道私有知识的问题，50 条评测准确率 80%+。」

## 1 分钟版结构

```
背景：项目解决什么问题，给谁用
方法：用了什么技术，为什么不选替代方案
结果：量化指标
收尾：我学到的一条最重要的经验
```

## 5 分钟版结构

```
1. 业务与用户
2. 核心流程
3. 数据来源与处理
4. 技术方案与选型
5. 评测与指标
6. 部署与上线
7. 失败案例与修复
8. 复盘与可迁移经验
```

## 技术决策记录

每个项目至少 2 个决策用 Lore 格式：

- 决策内容
- `Constraint:` 约束条件
- `Rejected:` 考虑过的替代方案 | 放弃原因
- `Confidence:` low / medium / high

## 失败故事模板

```
场景：我当时要解决什么问题
行动：我做了什么选择
失败：结果怎样，指标如何
复盘：错在需求理解 / 数据 / 方案 / 实现
修复：改成什么，结果如何
经验：以后遇到同类问题会怎么做
```

## 面试追问准备

- 为什么选这个模型/框架？
- 如果数据量翻 10 倍怎么办？
- 如果模型回答变差了怎么排查？
- 如果延迟过高怎么优化？
- 如果让你重做一次，会改哪里？

## 使用检查

- [ ] 每个项目都有量化指标
- [ ] 每个决策都有替代方案
- [ ] 每个项目都有 1 个真实失败案例
- [ ] 1 分钟版能自然说完
- [ ] 5 分钟版能讲 3–5 分钟
