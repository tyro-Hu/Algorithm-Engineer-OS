# 项目 3：多模态 Agent

> 目标：做一个能看、能听、能说的 Agent，把 CV、语音、多模态能力和 RAG 串起来。

## 一句话

用户通过语音或图片提问，Agent 用 OCR/ASR/VLM 理解输入，用 RAG 检索知识，用文本或语音回答。

## 成功指标

- 语音输入转文字准确率可量化
- OCR 能正确处理图片/扫描件
- 图文问答能返回合理答案
- 综合链路可用：语音提问 → 回答 → 语音播报
- 每个模态都有独立评测和 Bad Case

## 系统链路

```
语音输入 → ASR → 文本
图片输入 → OCR / VLM → 结构化信息
                    ↓
            统一指令 → Agent → RAG 检索 → 生成
                    ↓
            文本回答 → TTS → 语音输出
```

## 技术栈

- ASR：Whisper / FunASR
- OCR：PaddleOCR / Tesseract
- VLM：Qwen-VL / LLaVA
- TTS：开源 TTS 或云 API
- RAG：复用项目 1
- Agent：复用项目 2
- 后端：FastAPI

## 里程碑

### M1：单模态能力（第 1–3 周）

- 跑通 OCR
- 跑通 ASR
- 跑通 VLM
- 各记录 1 个 Bad Case

### M2：接进 RAG（第 4–6 周）

- 图片/扫描件 → OCR → 文本入库
- 语音 → ASR → 文本提问
- 图片问答 → VLM → RAG 检索补充知识

### M3：接进 Agent（第 7–9 周）

- OCR、ASR、VLM 作为 Agent 工具
- 支持混合输入：文字 + 图片 + 语音
- 记录工具调用失败场景

### M4：输出与部署（第 10–12 周）

- TTS 语音回答
- FastAPI + Docker 部署
- 评测和复盘

## 面试叙事

1 分钟版：这是一个多模态 Agent，用户能语音提问、上传图片，Agent 通过 ASR/OCR/VLM 理解输入，再走 RAG 回答，最后语音播报。它把 CV、语音、多模态和 Agent 能力串成了一个完整作品。

5 分钟版：按「输入模态 → 理解 → 工具调用 → 知识检索 → 生成 → 输出」讲，强调每个模态的评测、失败模式和为什么选这套架构。
