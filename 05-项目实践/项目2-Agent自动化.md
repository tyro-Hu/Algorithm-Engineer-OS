# 项目 2：Agent 自动化助手

> 目标：做一个能调用工具、有记忆、能处理多步骤任务的 Agent 系统，证明高薪 Agent 应用岗的核心能力。

## 一句话

用户给一个目标，Agent 自主规划步骤、调用工具、处理失败并给出结果。

## 成功指标

- 定义 10 个标准任务，任务成功率 ≥ 70%
- 平均任务完成时间 < 60 秒
- 记录每次调用的 Token 成本
- 失败时能重试或降级，不静默出错
- 工具调用有权限边界

## 系统链路

```
用户目标 → 任务规划 → 工具调用（Function Calling / MCP）
    → 记忆管理 → 多 Agent 分工 → 结果校验 → 输出
```

## 技术栈

- 框架：LangGraph 或 LangChain / LlamaIndex
- 协议：Function Calling、MCP
- 记忆：对话上下文 + 向量记忆（Chroma/FAISS）
- 后端：FastAPI
- 工具示例：文档查询、天气/计算器、数据库查询、RAG 检索、定时任务
- 部署：Docker

## 里程碑

### M1：单工具调用（第 1–2 周）

- 实现 2–3 个工具
- 让 LLM 通过 Function Calling 调用
- 记录参数错误、调用失败、结果幻觉

### M2：多步骤规划（第 3–4 周）

- 让 Agent 自己拆解任务
- 支持重试和失败降级
- 手动测试 10 个任务

### M3：记忆（第 5–6 周）

- 短期记忆：多轮对话
- 长期记忆：向量库保存用户偏好和历史
- 测试记忆召回效果

### M4：多 Agent（第 7–8 周）

- 规划 Agent + 执行 Agent + 校验 Agent
- 任务失败后能重新规划
- 记录多 Agent 通信和成本

### M5：安全与评测（第 9–10 周）

- 工具权限、沙箱、审批
- 10 个标准任务评测
- 输出成功率、延迟、成本

### M6：部署与复盘（第 11–12 周）

- FastAPI + Docker 部署
- 写项目复盘和面试叙事

## 面试叙事

1 分钟版：这是一个多 Agent 自动化助手，能拆解任务、调用工具、记忆用户偏好，失败自动重试。10 个标准任务成功率 70%+，平均耗时 X 秒，成本可控。

5 分钟版：按「任务 → 规划 → 工具 → 记忆 → 多 Agent → 安全 → 评测」讲，重点讲 1 个失败案例和 1 个设计决策。

## 验收清单

- [ ] 至少 5 个工具可调用
- [ ] 任务可自主拆解
- [ ] 长期记忆可复用
- [ ] 多 Agent 可分工
- [ ] 有权限边界
- [ ] 成功率、延迟、成本有记录
