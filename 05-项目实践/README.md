# 05-项目实践

本目录存放作品集项目的文档与复盘，代码放独立代码仓库，不放入知识库。

## 作品集主线

一线城市和合肥的 Agent 应用岗都看重「从 0 到 1 的落地项目」，12 个月保底 3 个项目：

- 详细规格见 `项目1-RAG知识库问答.md`
- 详细规格见 `项目2-Agent自动化.md`
- 详细规格见 `项目3-多模态Agent.md`

### 1. RAG 知识库问答系统

- 公开数据（文档/网页/Markdown）建知识库
- 分块 → Embedding → 向量检索 → 重排 → 生成 → 引用
- 至少一个向量库：FAISS / Chroma / Milvus / pgvector
- RAGAS 评测 + Bad Case 分析
- FastAPI + Docker 部署

### 2. Agent 自动化助手

- Function Calling / MCP 工具调用
- 记忆：短期对话 + 长期向量记忆
- 多 Agent：规划、分工、通信、失败重试
- 安全：工具权限、沙箱、审批、审计
- 任务成功率、延迟、成本记录

### 3. 多模态 Agent

- OCR：图片/扫描件进入知识库
- ASR：语音提问转文本
- TTS：回答语音播报
- VLM：图片问答 / 图文检索
- 综合链路：语音提问 → OCR/ASR → RAG → 回答 → 语音输出

## 每个项目的必交物

- 项目文档（目标、指标、方案、结果、复盘）
- 代码仓库（README + 可复现步骤）
- 演示视频或截图
- 面试 1 分钟版和 5 分钟版故事
- 至少一次「发现 Bad Case → 修复 → 对比」的迭代
