# 论文复现模板

> 用途：`04-案例拆解/` 下论文复现笔记的统一结构。
> 原则：复现不是跑通代码，而是能解释「为什么这样设计」。

## 论文信息
- 标题 / 作者 / 机构 / 发表年份 / 会议
- 一句话贡献

## 解决的问题
- 之前方法为什么不行？
- 本文提出了什么新假设 / 新结构 / 新目标函数？

## 核心方法
- 方法流程（数据 → 模型 → 损失 → 训练 → 推理）
- 关键设计决策及替代方案（Lore 格式：`Constraint:` / `Rejected:` / `Confidence:`）

## 复现实验
- 数据集、评价指标、基线
- 我的实现与原论文差异
- 实验结果（指标表 / 曲线 / 截图）
- 失败与踩坑

## 结论与迁移
- 这个方法解决的本质问题是什么？
- 我可以迁移到哪个项目 / 场景？
- 2–3 条可复用经验
