# 技术学习模板（七段式）

> 用途：`03-知识沉淀/` 下所有技术笔记的统一结构。
> 原则：先回答问题，再展开细节；禁止概念罗列。

## 模板

### 背景问题
为什么出现？解决什么痛点？不解决会怎样？

### 演进过程
以前如何解决？经历了哪些阶段？每个阶段为什么被替代？

### 核心思想
本质是什么？一句话说清。核心机制是什么？损失函数 / 算法步骤 / 数学直觉是什么？

### 算法 / 系统位置
属于技术地图哪一层？在算法研发链路（数据 → 特征 → 模型 → 评估 → 上线 → 迭代）中处于什么位置？

### 真实案例
哪个真实系统或项目在用？解决了什么业务问题？效果如何衡量？

### 面试视角
面试官可能怎么问？最容易被追问的推导、边界条件、失败模式是什么？

### 实践任务
如何验证理解？可运行的最小实验是什么？实验指标和结论是什么？

## 使用清单

- [ ] 先回答六问，答不上来就再研究
- [ ] 按七段填充，每段控制在 300 字内
- [ ] 关联技术地图位置 + 至少一个真实案例
- [ ] 完成实践任务并记录结果
