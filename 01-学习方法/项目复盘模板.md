# 项目复盘模板

> 用途：`05-项目实践/` 下每个项目的统一结构。
> 原则：复盘是决策质量的体检，不是成绩单。

## 项目信息
- 项目名称 / 时间 / 角色
- 一句话目标
- 成功指标（离线指标 + 线上/业务指标）

## 算法链路设计
- 业务 → 用户 → 核心流程 → 数据来源 → 特征 → 模型选型 → 评估 → 上线 → 迭代
- 关键决策记录（Lore 格式）：
  - `Constraint:` 约束条件
  - `Rejected:` 替代方案 | 放弃原因
  - `Confidence:` low / medium / high

## 实现与验证
- 完成的功能 / 未完成的
- 验证方式与结果（测试、指标、A/B、用户反馈）

## 复盘
- **做得好**：哪些决策被验证正确？
- **做得差**：哪些决策错了？错在哪一步（需求理解 / 数据 / 特征 / 模型 / 评估）？
- **意外收获**：计划外但有用的发现
- **如果重来**：会改变什么？为什么？

## 沉淀
- 沉淀到 `03-知识沉淀/` 的知识点
- 新问题（同步到 `07-问题库/`）
- 面试可讲的 1 分钟故事版和 5 分钟详细版
