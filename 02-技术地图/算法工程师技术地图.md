## ② 数学与统计

- 线性代数：向量空间、矩阵运算、特征值、SVD、低秩近似
- 概率统计：条件概率、贝叶斯、常见分布、MLE/MAP、假设检验、置信区间、A/B 实验
- 微积分：偏导、链式法则、梯度、泰勒展开
- 优化：梯度下降、SGD/Adam/AdamW、凸优化概念、数值稳定性、损失函数设计

**掌握标准**：能推导常用损失的梯度，能解释训练不稳定的数学原因。

**状态**：🟡 有基础，需按面试深度重过

## ③ 编程与算法

- Python 工程化：类、装饰器、生成器、上下文管理器、类型提示、单元测试、调试
- 第二语言：C++/Java/Go 至少一门，能读懂并能写简单模块
- 数据结构：数组、链表、栈、队列、哈希、树、堆、图
- 算法：排序、二分、双指针、滑动窗口、递归、DFS/BFS、回溯、DP、贪心、并查集
- 复杂度分析：时间/空间复杂度、海量数据处理思想

**掌握标准**：LeetCode 中等题稳定通过，能讲清每个模板的复杂度与边界。

**状态**：🟡 Python 强，刷题待启动

## ④ 机器学习

- 经典模型：线性/逻辑回归、SVM、KNN、朴素贝叶斯、决策树、随机森林、GBDT/XGBoost/LightGBM
- 无监督：KMeans、DBSCAN、PCA/SVD、Embedding
- 特征工程：缺失值、离散化、归一化、编码、组合特征、样本不均衡
- 评估：准确率、精确率、召回率、F1、ROC/AUC、PR、MAE/RMSE、NDCG、交叉验证
- 泛化：过拟合、正则化、偏差-方差、数据泄漏、分布偏移
- 实验：A/B 测试、显著性、样本量、因果推断基础

**掌握标准**：面对新任务能先选基线模型，能设计评估方案并解释指标取舍。

**状态**：🔴 待系统化

## ⑤ 深度学习

- 基础组件：MLP、激活函数、损失、优化器、初始化、正则化、归一化
- 经典结构：CNN、RNN/LSTM、Attention、Transformer、BERT/GPT、ViT
- 训练工程：学习率策略、梯度裁剪、混合精度、断点续训、实验追踪、超参调优
- 生成模型：VAE、GAN、Diffusion 概念理解
- PyTorch：Dataset/DataLoader、autograd、训练循环、AMP、多卡/分布式训练基础

**掌握标准**：能从头实现小型 Transformer，能解释训练不稳定的原因并修复。

**状态**：🟢 有基础，需深化 Transformer 与训练工程

## ⑥ 数据与大数据

- SQL：JOIN、窗口函数、聚合、索引、慢查询
- 数据处理：Pandas、NumPy、EDA、数据清洗、去重、脱敏、版本管理
- 大数据：Hadoop/Hive/Spark/Flink 定位、数据分片、批流处理
- 特征平台：特征存储、离在线一致性、样本拼接

**掌握标准**：能独立完成「原始数据 → 清洗 → 特征 → 训练样本」的完整链路。

**状态**：🔴 主要缺口

## ⑦ 大模型与 Agent 应用

- LLM 原理：Tokenization、Positional Encoding、Attention、KV Cache、上下文窗口、Scaling Laws
- 微调：SFT、LoRA/QLoRA、DPO/RLHF/GRPO 概念、偏好数据
- RAG：文档解析、分块、Embedding、向量检索、混合检索、重排、引用溯源、知识更新
- Agent 工程：Function Calling、MCP、规划、记忆、工具调用、多 Agent、沙箱与安全
- 向量库：FAISS、Chroma、Milvus、pgvector
- 框架：LangGraph / LangChain / LlamaIndex / Dify
- 后端：FastAPI、Docker、PostgreSQL/Redis、SSE
- 评测：Benchmark、RAGAS、幻觉检测、人工评测、Bad Case 分析、在线 A/B
- 推理：vLLM、量化、批处理、服务化、成本与延迟

**掌握标准**：能独立完成 RAG 和 Agent 的端到端项目，能讲清每个环节的失败模式。

**状态**：🟡 有实践，需原理与评测闭环

## ⑧ 工程化与面试

- 工具链：Git、Docker、实验追踪（MLflow/W&B）、CI/CD
- 部署：FastAPI、模型服务、监控、日志、告警
- 模型上线：版本管理、灰度、回滚、漂移检测
- 面试：LeetCode 模板、ML/DL 理论题、LLM 题、项目故事、行为面试

**掌握标准**：能讲清「模型从训练到上线的完整链路」并回答每一层的故障场景。

**状态**：🔴 主要缺口

## ⑨ 多领域支撑（Agent 视角）

以 Agent 应用为主线，NLP、CV、语音、多模态都作为 Agent 的输入/输出能力，每个领域至少做出一个可集成的最小能力。

### NLP（核心）

- 经典 NLP：分词、词向量、HMM/CRF、词性标注、句法、语义
- 预训练模型：BERT/GPT、微调、序列标注、文本分类、抽取式 QA
- LLM 应用：Prompt、RAG、Agent、微调、评测
- 任务：文本分类、NER、问答、摘要、对话、语义检索

**状态**：🟢 有基础，需深化

### 计算机视觉（Agent 的“眼睛”）

- 最小能力：OCR（PaddleOCR/Tesseract）、文档/图片解析
- 概念：图像基础、OpenCV、CNN、检测/分割
- 进阶按需：YOLO、U-Net、ViT、视频理解

**状态**：🔴 从零开始

### 语音（Agent 的“耳朵和嘴巴”）

- 最小能力：ASR（Whisper/FunASR）、TTS
- 概念：FFT、FBank、MFCC、CTC、Conformer、WER/CER
- 工具：WeNet、ESPnet、AISHELL、LibriSpeech

**状态**：🔴 从零开始

### 多模态（Agent 综合能力）

- 表示学习：对比学习、跨模态对齐、CLIP
- 模型：VLM、BLIP、LLaVA、图像描述、VQA
- 任务：图文检索、视觉问答、跨模态生成、音视频+文本

**状态**：🔴 待前三领域基础齐备后学习

**掌握标准**：OCR、ASR、TTS、VLM 各有一个可集成到 Agent 的最小能力；多模态 Agent 项目把它们串起来。
