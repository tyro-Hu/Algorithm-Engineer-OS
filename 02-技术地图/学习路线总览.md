# 算法工程师学习路线总览

> 最后更新：2026-08-13
> 目标：全国一线城市 + 合肥 · Agent 应用开发工程师（社招，工资优先），12 个月，兼顾工作
> 基准投入：每天 1–2 小时（约每周 8–12 小时），项目 + 基础 + 刷题并行
> 原则：项目驱动，先做出可演示能力，理论按需补

## 核心主线

```
LLM 原理 + RAG + Function Calling
    ↓
Agent 工程：MCP / 多 Agent / 记忆 / 向量库 / 后端
    ↓
多模态输入输出：OCR / ASR / TTS / VLM 集成进 Agent
    ↓
作品集：3 个项目 + 面试冲刺
```

> 详细内容见 `02-技术地图/多领域学习路线.md` 和 `00-岗位与定位/启动决策摘要.md`。

## 阶段 0：定位与准备（第 1 月）

目标：确定岗位要求、搭好环境、跑通第一个最小 Demo。

- 读 `00-岗位与定位/市场岗位调研.md` 和 `启动决策摘要.md`
- 搭好 Python/PyTorch 环境，确认 Colab / 实验室 GPU 可用
- 用现有 RAG 经验跑通一个最小问答 Demo
- 开始 LeetCode：数组、哈希表

交付：
- 个人画像和启动决策
- 最小 RAG Demo
- 环境说明

## 阶段 1：Agent 工程核心（第 2–4 月）

目标：把 RAG 从 Demo 做成可评测、可部署的项目。

学习内容：
- LLM 原理：Prompt、Context Engineering、Token、模型选型
- RAG：分块、Embedding、混合检索、重排、引用、知识更新
- 向量库：FAISS、Chroma、Milvus、pgvector 至少精通一个
- 后端：FastAPI、Docker、PostgreSQL/Redis
- 评测：RAGAS、Bad Case、召回率、答案质量

交付：
- 项目 1：RAG 知识库问答（公开数据，端到端部署）
- 至少 2 篇七段式笔记

## 阶段 2：Agent 深潜（第 5–7 月）

目标：掌握 Agent 工程化，做出第二个作品集项目。

学习内容：
- Function Calling、Tool/API 封装
- MCP、LangGraph / LangChain / LlamaIndex / Dify 至少熟悉一个
- 记忆：短期上下文、长期记忆、向量记忆
- 多 Agent：规划、分工、通信、失败重试
- 安全：工具权限、沙箱、审批、审计
- 评测：任务成功率、延迟、成本、失败模式

交付：
- 项目 2：Agent 自动化助手（工具调用 + 记忆 + 多 Agent）
- 项目复盘 1 篇

## 阶段 3：多领域支撑（第 8–10 月）

目标：让 Agent 能看、能听、能说，用多模态能力补齐 CV、语音、多模态知识。

学习内容：
- CV 支撑：OCR 集成，图片/文档解析进入 RAG
- 语音支撑：ASR 作为 Agent 输入，TTS 作为 Agent 输出
- 多模态支撑：VLM 做图片问答、图文检索
- 综合：语音提问 → OCR/ASR → RAG → 回答/语音播报

交付：
- 项目 3：多模态 Agent（至少整合 OCR + ASR + RAG）
- CV、语音、多模态各 1 篇入门笔记

## 阶段 4：面试冲刺（第 11–12 月）

目标：把项目、基础、刷题转换成一线城市/合肥的高薪社招机会。

内容：
- 算法题：高频题 + 错题重刷
- 理论题：LLM、RAG、Agent、后端、系统设计
- 项目叙事：3 个项目按「背景 → 难点 → 方案 → 结果 → 复盘」打磨
- 模拟面试：每周 1 次，录下复盘
- 简历：按 Agent 应用岗定制，突出工具调用、向量库、部署、指标

交付：
- 可投递简历
- 高频题题库 + 标准答案
- 3 轮模拟面试复盘

## 每周工作流

```
确定本周 1 个任务 → 最小实现 → 记录结果 → 刷 2–3 题
→ 每周日志 → 问题入库 → 下周调整
```

## 验收总标准

- [ ] 3 个项目都能演示：RAG 知识库、Agent 自动化、多模态 Agent
- [ ] 能讲清 RAG、Function Calling、MCP、多 Agent、记忆的失败模式
- [ ] 能用 OCR、ASR、VLM 给 Agent 加多模态能力
- [ ] LeetCode 中等题稳定通过
- [ ] 完成至少 3 轮模拟面试
- [ ] 简历覆盖一线城市 Agent 应用岗的核心关键词
