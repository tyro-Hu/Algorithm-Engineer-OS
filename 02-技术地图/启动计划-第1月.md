# 第 1 个月启动计划

> 目标：完成定位、搭好环境、跑通 RAG 和 Agent 最小 Demo，建立每周节奏。
> 基准：每天 1–2 小时（约每周 8–12 小时），工作日每天 30–60 分钟，周末 2–4 小时。
> 来源：本文件是 `任务清单.md` 阶段 0 的按月拆解，完成情况以任务清单为准。

## 第 1 周：定位与环境

任务：
- 读 `00-岗位与定位/市场岗位调研.md` 和 `启动决策摘要.md`
- 确认一线城市/合肥 Agent 应用岗的核心关键词
- 搭好 Python 环境，确认 Colab / 实验室 GPU 可用
- 开始刷题：数组、哈希表，本周完成 8–10 题
- 写一篇「一线城市 Agent 应用岗要什么」的短文沉淀

产出：
- 个人画像和启动决策
- 环境说明

## 第 2 周：最小 RAG Demo

任务：
- 用现有 RAG 经验 + 公开数据，跑通一个最小问答 Demo
- 至少用一个向量库：FAISS 或 Chroma
- 记录分块、Embedding、检索、生成四步
- 补 LLM 原理：Prompt、Token、上下文窗口、模型选型
- 刷题：链表、栈、队列，本周完成 6–8 题

产出：
- 可演示的最小 RAG Demo
- 一张链路图

## 第 3 周：最小 Agent Demo

任务：
- 用 FastAPI 封装一个工具调用接口
- 让 LLM 通过 Function Calling 调用计算/查询/检索工具
- 记录失败场景：工具参数错误、调用超时、结果幻觉
- 了解 MCP 概念，尝试接一个外部工具
- 刷题：二分、双指针、滑动窗口

产出：
- 可演示的最小 Agent Demo
- 至少 3 个失败案例

## 第 4 周：多模态第一次接触

任务：
- 跑通 OCR：把一张图片/扫描件转成文本
- 跑通 ASR：录一句话转成文本
- 跑通 VLM：对一张图片做简单问答
- 用七段式模板写 2 篇笔记（RAG、Agent 各 1 篇）
- 把陌生概念记入 `07-问题库/`
- 刷题：DFS/BFS、回溯、DP 入门

产出：
- OCR / ASR / VLM 各一个最小结果
- 第 1 个月复盘
