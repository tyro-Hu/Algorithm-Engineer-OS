# 多领域学习路线：Agent 应用视角

> 最后更新：2026-08-13
> 目标：12 个月内，以 Agent 应用开发工程师为核心，NLP、CV、语音、多模态都覆盖，但按“Agent 输入/输出能力”组织，不追求独立算法岗深度。

## 学习顺序

```
RAG + Agent（核心，先做项目）
    ↓
CV 支撑（OCR 让 Agent 看得懂文档/图片）
    ↓
语音支撑（ASR 让 Agent 听得懂，TTS 让 Agent 说得出）
    ↓
多模态（VLM 让 Agent 能看图问答、图文检索）
    ↓
多模态 Agent 综合项目
```

## 一、NLP / RAG / Agent（核心，约 3 个月）

这是一线城市和合肥 Agent 应用岗共同的求职主战场。

### RAG 必须掌握

- 文档解析与分块
- Embedding 模型选型
- 向量库：FAISS / Chroma / Milvus / pgvector
- 混合检索：向量 + 关键词
- 重排 Reranker
- 引用溯源与知识更新
- 评测：RAGAS、召回率、答案相关性、Bad Case

### Agent 必须掌握

- Prompt / Context Engineering
- Function Calling 与工具封装
- MCP
- 记忆：短期、长期、向量记忆
- 多 Agent 规划与通信
- 失败重试、沙箱、权限、审计
- 至少一个框架：LangGraph / LangChain / LlamaIndex / Dify

### 项目

- 项目 1：RAG 知识库问答（公开数据，部署 API）
- 项目 2：Agent 自动化（工具调用 + 记忆 + 多 Agent）

## 二、计算机视觉：作为 Agent 的“眼睛”（约 1 个月）

目标不是做独立 CV 算法岗，而是让 Agent 能处理图片和文档。

### 最小知识

- 图像基础：像素、色彩、格式
- OCR：PaddleOCR / Tesseract 集成
- 文档解析：扫描件、表格、截图
- 检测/分割概念：能看懂 YOLO、U-Net 输出即可
- 进阶按需：图片分类、人脸、视频理解

### 项目

- 把 OCR 接进 RAG：图片/扫描件 → OCR → 文本入库 → 问答

## 三、语音：作为 Agent 的“耳朵和嘴巴”（约 1 个月）

目标：Agent 能接收语音输入，也能用语音输出。

### 最小知识

- 信号与特征：FFT、FBank、MFCC 概念
- ASR：Whisper / FunASR / WeNet 集成
- TTS：语音合成、声音选择、流式播报
- 概念：CTC、Conformer、WER/CER 了解即可

### 项目

- 把 ASR + TTS 接进 Agent：语音提问 → 文本 → Agent 回答 → 语音播报

## 四、多模态：VLM 让 Agent 看图说话（约 1 个月）

目标：把文本、图像、语音串起来。

### 最小知识

- CLIP：图文对齐、对比学习
- VLM：Qwen-VL / LLaVA / BLIP 使用与 API
- 图文检索：Recall@K
- 视觉问答、图像描述
- 多模态 Agent 输入：图片 + 文字 + 语音混合

### 项目

- 项目 3：多模态 Agent：语音提问 + OCR/图片 + RAG + 回答（可选语音播报）

## 五、综合项目与评测（约 1 个月）

把三个项目整合成一条可讲的故事线：

```
用户（语音/文字/图片） → Agent 理解 → 工具调用（OCR/ASR/检索）
→ RAG 回答 → 引用溯源 → 语音/文本输出
```

必须记录：
- 任务成功率、延迟、成本
- Bad Case 与一次迭代
- 项目复盘与面试叙事

## 学习原则

1. 先跑通，再补原理：每个能力先用现成模型/框架集成，遇到问题再学底层。
2. 一个项目串多个领域：多模态 Agent 天然覆盖 CV、语音、多模态。
3. 评测贯穿：RAG 看答案质量，Agent 看任务成功率，语音看 WER/CER，CV 看 OCR 准确率。
4. 不囤资料：每学一个能力，必须产出可演示结果。
5. 如果时间增加，优先加深 RAG/Agent，再扩展 CV/语音理论。
